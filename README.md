# 🔪 Ficha Brutal RPG

Site com sistema de login para mestre e player poderem editar suas fichas e campanhas.

## Sobre o projeto

A **Ficha Brutal RPG** é um projeto feito para praticar banco de dados. 
O site permite que um usuário se cadastre ou faça login e tenha acesso a suas fichas do sistema **BRUTAL**, podendo criar, editar ou excluir fichas.

## Linguagens utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **SQL**
